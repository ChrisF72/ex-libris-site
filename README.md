# ex-libris-site

Les deux pages publiques exigees par Google pour l'application Android **Ex-Libris**
(`fr.exlibris.bibliotheque`) : une page d'accueil et des regles de confidentialite.

- Accueil : https://chrisf72.github.io/ex-libris-site/
- Confidentialite : https://chrisf72.github.io/ex-libris-site/confidentialite.html

Ce depot ne contient **que** ces pages. Le code source de l'application vit dans un depot
prive et separe. Aucune cle, aucune empreinte de signature, aucune adresse e-mail ici.
